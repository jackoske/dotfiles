---
description: Produce a durable, truthful handoff summary for continuing work.
---

Write a concise handoff in the response for the current request. Include:
objective and scope, approved decisions and acceptance criteria, completed
work, files changed, checks and exact results, unresolved risks or blockers, and
the recommended next action. Separate confirmed evidence from assumptions.
Use only information available in this session; do not pretend to inspect
unavailable state and do not write a file unless the user explicitly approves a
path.
